ChatModel
底层模型调用能力
ChatClient
对 ChatModel 的高级封装
├── System Prompt
├── User Prompt
├── Chat Memory
├── Advisor
├── Tool Calling
└── 结构化输出


┌─────────────────────────────────────────────────────────────────────────────┐
│                           【业务调用层】                                    │
│              (你的 Service/Controller 代码)                                │
│                                                                             │
│  String result = chatClient.prompt().user("你好").call().content();        │
└───────────────────────────────────┬─────────────────────────────────────────┘
│ 依赖（门面入口）
▼
┌─────────────────────────────────────────────────────────────────────────────┐
│                      【高级封装层 - ChatClient】                           │
│                                                                             │
│  职责：  │  • 提供流式 API (prompt().user().advisors().call())            │
│          │  • 管理对话记忆 (ChatMemory Advisors)                          │
│          │  • 集成函数调用 (Function Calling)                             │
│          │  • 异常处理与日志拦截                                          │
│                                                                             │
│  工作流：  (接收参数) → 构建 Prompt → 调用底层 → 封装结果                │
└───────────────────────────────────┬─────────────────────────────────────────┘
│ 委托调用（依赖注入）
▼
┌─────────────────────────────────────────────────────────────────────────────┐
│                      【底层模型层 - ChatModel】                            │
│                                                                             │
│  职责：  │  • 定义与 AI 模型交互的标准化接口 (OpenAI/Ollama/通义...)     │
│          │  • 处理 HTTP 连接、API Key 鉴权、超时重试                     │
│          │  • 序列化请求 (JSON) 与反序列化响应                           │
│          │  • 流式/同步响应的原始数据接收                                │
│                                                                             │
│  实现类： OpenAiChatModel, AzureOpenAiChatModel, OllamaChatModel ...      │
└───────────────────────────────────┬─────────────────────────────────────────┘
│ 产生（返回原始数据）
▼
┌─────────────────────────────────────────────────────────────────────────────┐
│                    【数据传输对象 - ChatResponse】                         │
│                    (标准化响应容器，屏蔽底层差异)                          │
│                                                                             │
│  ┌─────────────────────────────────────────────────────────────────────┐   │
│  │  ChatResponse 内部结构 (Spring AI 标准)                            │   │
│  │                                                                     │   │
│  │  ├── result : ChatResult                                           │   │
│  │  │     ├── output : AssistantMessage                               │   │
│  │  │     │     ├── text : String        ← 你代码里取的 content      │   │
│  │  │     │     └── metadata : Map       (角色、工具调用信息等)      │   │
│  │  │     └── metadata : ChatResponseMetadata                         │   │
│  │  │           ├── tokenUsage : TokenUsage (Prompt Tokens, Complet..)│   │
│  │  │           ├── model : String       (实际使用的模型名称)         │   │
│  │  │           └── finishReason : String (停止原因: STOP/LENGTH)    │   │
│  │  └── (可选) multipleResults : List<ChatResult>  (支持多候选回复)  │   │
│  └─────────────────────────────────────────────────────────────────────┘   │
└─────────────────────────────────────────────────────────────────────────────┘
