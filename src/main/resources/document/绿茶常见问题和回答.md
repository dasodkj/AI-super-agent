# 绿茶常见问题和回答：从选茶到冲泡

绿茶的风味常给人清鲜、爽口的印象。想泡出一杯好喝的绿茶，可以先从水温、投茶量和保存方法入手。

#### 1. 绿茶一定要用低温水冲泡吗？

答：不一定。冲泡温度要结合具体茶品、茶水比例、浸泡时间和个人口味调整。日常冲泡部分细嫩绿茶时，可以先尝试约 80～90℃，但这不是所有绿茶的统一标准，也不能只凭芽叶嫩度决定水温。茶及饮料作物改良场对所选碧螺春茶样的试验发现，80～90℃的感官表现优于沸水；这一结果适用于该试验条件，不能直接推广到所有绿茶。[资料来源：水质及水温对茶汤品质之影响](https://www.tbrs.gov.tw/ws.php?id=5283&print=Y)。

建议课程主题（未核实开设）：[《绿茶冲泡入门：水温与滋味的关系》](https://www.codefather.cn)。

#### 2. 为什么自己泡的绿茶总是很苦？

答：常见原因是投茶量偏多、浸泡时间过长，或者水温与茶叶特点不匹配。可以先减少投茶量，再缩短浸泡时间，观察滋味是否改善。建议每次只调整一个因素，方便找到适合自己的冲泡方式。部分绿茶本身带有一定苦涩感，也不能单凭这一点判断品质。

建议课程主题（未核实开设）：[《茶汤风味调整：投茶量与浸泡时间》](https://www.codefather.cn)。

#### 3. 泡绿茶应该选择玻璃杯还是盖碗？

答：两种都可以。玻璃杯适合日常饮用，也便于观察茶叶舒展；但茶叶持续浸在水中，茶汤容易逐渐变浓。盖碗可以在合适的时间倒出茶汤，更方便控制浓淡、比较不同泡次的变化。初学者可以根据自己的饮茶习惯选择，不需要为了喝绿茶购买昂贵茶具。

建议课程主题（未核实开设）：[《茶具使用基础：玻璃杯与盖碗冲泡》](https://www.codefather.cn)。

#### 4. 绿茶开封后应该怎样保存？

答：重点是密封、避光、防潮、低温和远离异味。可以用阻光、防潮、无异味的包装分成小份，减少整包反复开合。采用冷藏方式时，应可靠密封并与有强烈气味的食品隔开；取出后先保持包装密闭，待恢复到室温再打开，以减少冷凝水导致受潮的机会，避免同一大包茶频繁进出冰箱。冷藏不能恢复已经受潮变质的茶叶，保存方法和期限应参考产品包装说明。[包装与贮藏依据](https://www.tbrs.gov.tw/ws.php?id=4829&print=Y)；[冷藏回温说明](https://www.bjcc.gov.cn/article/600478749.html)。

建议课程主题（未核实开设）：[《家庭茶叶保存：绿茶保鲜方法》](https://www.codefather.cn)。

#### 5. 绿茶是不是颜色越绿，品质就越好？

答：不是。不同品种和加工方式的绿茶，正常色泽本来就有差异。例如黄山毛峰可以呈现绿中泛黄、带金黄色鱼叶的外观，这并不意味着品质差。评价时应结合该茶品应有的特征，以及香气、滋味、汤色、叶底和保存状态，不能跨茶品只按“谁更绿”排序。[资料来源：黄山市政府关于黄山毛峰的介绍](https://www.huangshan.gov.cn/zwgk/public/6615714/11236663.html)。

建议课程主题（未核实开设）：[《绿茶品鉴基础：外形、香气与滋味》](https://www.codefather.cn)。
