# 红茶常见问题和回答：认识香气与冲泡技巧

红茶的风味丰富，有的偏甜香，有的带花香或果香。了解原料、工艺和冲泡方式的差异，有助于找到适合自己的口味。

#### 1. 红茶和绿茶的主要区别是什么？

答：两者的重要区别在于加工过程中对酶促氧化的控制。绿茶通过杀青使相关酶失活，抑制后续酶促氧化；红茶则通常经过萎凋、揉捻或揉切、发酵及干燥等工序，形成相应的色泽和风味。红茶工艺中的“发酵”主要指茶叶内多酚类物质参与的酶促氧化，并不等同于酸奶那样的微生物发酵。“全发酵茶”也是茶类工艺术语，不表示茶叶中的所有成分都已完全氧化。[资料来源：茶叶加工制程简介](https://www.tbrs.gov.tw/ws.php?id=4748)。

建议课程主题（未核实开设）：[《六大茶类入门：认识绿茶与红茶工艺》](https://www.codefather.cn)。

#### 2. 红茶应该用多少度的水冲泡？

答：不少红茶可以从约 90℃至沸水的范围尝试，再根据茶品说明和口味调整。茶及饮料作物改良场的试验中，所选红茶在90℃至沸水条件下的感官表现优于80℃。茶叶较碎或投茶较多时，通常更需要控制浸泡时间；不能简单认为细嫩红茶一定要低温，或只有条索紧实的红茶才能用沸水。[资料来源：水质及水温对茶汤品质之影响](https://www.tbrs.gov.tw/ws.php?id=5283&print=Y)。

建议课程主题（未核实开设）：[《红茶冲泡实操：水温与出汤控制》](https://www.codefather.cn)。

#### 3. 红茶闻起来有甜香，是否说明添加了糖？

答：不一定。红茶在原料和加工工艺的共同作用下，可以形成让人联想到蜂蜜、熟果或焦糖的香气。“闻起来甜”是香气描述，不等于茶汤含有添加糖，也不等于入口一定很甜。中国农业科学院茶叶研究所报道的红茶研究就识别出了甜香、果香等感官特征及相关成分。判断产品标示是否添加糖、香料或其他原料，应查看配料表和产品说明，不能仅凭闻香下结论。[资料来源：红茶品质研究](https://tri.caas.cn/xwzx/gzjb/3bebeb5a5e834c8c93f6ba1500085106.htm)。

建议课程主题（未核实开设）：[《红茶香气识别：蜜香、果香与甜香》](https://www.codefather.cn)。

#### 4. 红茶可以加牛奶吗？应该怎样选择？

答：可以。制作奶茶时，可以尝试滋味较浓、与牛奶混合后仍能保留茶味的红茶，例如一些红碎茶。制作时先泡出浓度适当的茶汤，再逐步加入牛奶，调整到自己喜欢的比例。对于花香细腻的红茶，也可以先清饮，感受原有风味后再决定是否调饮。

建议课程主题（未核实开设）：[《家庭奶茶制作：红茶选择与比例调整》](https://www.codefather.cn)。

#### 5. 红茶茶汤放凉后变浑浊，是不是坏了？

答：不一定。部分红茶茶汤冷却后会出现“冷后浑”，也称“茶乳酪”，与茶黄素、茶红素、咖啡碱等成分形成聚集体有关，并不表示加入了乳制品。它的形成还受到茶汤浓度和冲泡水的酸碱度等因素影响，因此不能仅凭浑浊判断品质高低或饮用安全。如果茶汤受到污染、保存不当或出现异常气味，不应把它一概解释成正常冷后浑；没有异味也不能单独证明安全。[资料来源：茶乳酪形成及组成研究](https://doi.org/10.1002/jsfa.2740190910)。

建议课程主题（未核实开设）：[《红茶品鉴进阶：认识茶汤色泽与冷后浑》](https://www.codefather.cn)。
